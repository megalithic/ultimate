A project switcher at the window's left edge: every Ultimate running on this machine, one click away, and the ones that ran here before.

## How it works

- **Rail** (`shell.rail`, on desktop and tablet; nothing on a phone): one row per running instance, in project order, then the stopped projects. It shows while it has at least two rows, running or stopped.
  - Collapsed, the rail is one quiet column of colour, a swatch per project and no letters (`ProjectSwatch` from the sidebar's `ui.solid.tsx`). Ultimate's own family (`ultimate`, `ultimate-eval`, a branch checkout of it) is the brand purple; every other project takes a muted, cool hue (sage, teal, blue; no warm hues, so nothing reads as amber or red, and no violet, which stays Ultimate's), derived from the folder name alone (`colourOf` in the sidebar's `colour.ts`, small and exported for other overviews), so a project keeps its colour on every instance and in the sidebar's header. Projects sharing a name stem (`ultimate`, `ultimate-eval`, `ultimate-fleet`) take neighbouring shades of one hue, and their adjacent swatches join into one strip with a gap before the next family. Other projects' swatches are slightly faded until hovered; the one this page shows is wider and full colour, ringed, with a brand bar on the edge. The swatch, its amber count and its working dot share the column's vertical axis.
  - Hovering opens it over the app (272 px); the pin button keeps it open beside the app. Each row then shows the display name (`prettyName`), and under it the GitHub `owner/repo` with a lock when private, and the port. The pin is one value for every instance on this machine (`~/.ultimate/projects-rail.json`), so jumping keeps the rail as it was.
  - On a page opened over the tailnet a row goes to the host the page came from, on that project's Tailscale port (`tailnetPort`, from the registry `~/.ultimate/tailscale.json`), since a loopback address means nothing there. A project not published on the tailnet shows dimmed, with no link. `links.ts` decides both from the page's host.
  - A row is a plain link to the instance's `/`, which opens its @ultimate: a click goes there in this tab, mod-click or middle-click opens a new tab, Back returns. The old page stays until the new one paints (seconds while the target builds its web bundle), so a click pulses its swatch, says "opening…" and runs a thin brand bar along the window's top; a page restored by Back clears it.
  - Live state, polled every 4 s while the tab is visible: an amber count of questions waiting for the user, else a pulsing brand dot while an agent works (questions outrank working; the two never show together). Folded, they sit on the swatch: amber is the only warm colour in the column, so a project waiting on you stands out. The footer sums it up (`1 for you · 2 working`).
- **Stopped projects:** every project with a state home in `~/.ultimate/projects/` that runs no instance now, under a quiet "Stopped" divider, most recently active first. Folded, each is a faint swatch; open, a muted row with its repo and when it was last active (the newest input or answer in its conversations, or its last opening). Hovering shows **Start**, which runs `mega start <root>` (the user's dotfiles script) in its own process group, so the instance outlives this one; once it holds its lock the row moves up among the running ones, and while it is still starting the row shows what `mega` printed (or its failure). **Forget**, which hides the row until the project opens again. Forget writes `{ <state home>: <time> }` to `~/.ultimate/projects-forgotten.json` and nothing else: the state home, its conversations and worktrees stay, and `ultimate.projects()` still lists it.
- **The hub:** the project whose folder is `fleet.primary` in `~/.ultimate/settings.json` (Fleet's setting) carries a small `hub` tag.
- **Another rail wins:** when any other enabled extension fills `shell.rail` (a fleet switcher of your own, say), this one renders nothing and stops polling, so the window never shows two rails.

## Files

- `server.ts`
  - `list`, `{}` → `RunningProject[]` (`refs.ts`): the projects `host.projects()` finds running (their supervisor lock is held by a live process), each with its loopback URL; a branch checkout's name is `<project> #<id>`, so it shows and colours with its project. Each carries its `origin`'s GitHub `repo` (`{name, url, visibility?}`) once known: read in the background on first sight (`git`, then one `gh repo view`) and kept for the process, so a poll never waits on it. This instance's `busy` and `questions` come from its own conversations and open questions; every other instance's from its `status` action over loopback, waiting at most 1.5 s. One that does not answer in time is listed without them.
  - `stopped`, `{}` → `StoppedProject[]`: the stopped projects not forgotten since they last opened.
  - `forget`, `{ home }` → `{}`: hides a stopped project until it opens again.
  - `start`, `{ home }` → `{ output }`: runs `mega start <root>` for a stopped project and returns what it printed; fails with its output.
  - `pin`, `{ pinned? }` → `{ pinned }`: the shared pin, written first when `pinned` is given.
- `rail.solid.tsx`: the rail and the opening bar, registered in `web.solid.tsx`.
